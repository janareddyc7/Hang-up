# Hang Up

Hang Up is a web app for practicing how to recognize and respond to phone scams. An AI caller acts out a fictional scam scenario, then the app shows a replay with the tactics used and tips for next time.

## Tech stack

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Neon Postgres, Drizzle ORM, Better Auth, ElevenLabs Agents, Vercel AI SDK, and Vercel.
