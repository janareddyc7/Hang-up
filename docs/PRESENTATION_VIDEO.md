# Three-minute Hang Up presentation

## Before recording

- Use the offline text path if ElevenLabs is slow or unavailable. It follows the same Director and replay flow without using voice minutes.
- Sign in before recording if you want to show Practice, Family Circle, and Settings. Keep a separate browser window ready on `/judge` as a public fallback.
- Use only fictional details from the Practice Wallet. Do not show real email, phone, bank, or API-key data.
- Do not claim a learning effect or quote a pilot result. The pilot and 200-label calibration set have not been collected yet.

## Run of show (3:00)

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:20 | Home page | “Phone scams work by creating pressure before we have time to think. Hang Up is a safe place to practice what to do next.” |
| 0:20–0:40 | Judge mode and disclosure | “A fictional AI caller uses a common tactic. This is a simulation, not a real call or a scam detector. You can use voice or text.” |
| 0:40–1:20 | Start a call, read the caller line, push back once, then hang up | “I’ll practice one response: I’m going to call back using a number I already trust.” |
| 1:20–2:00 | Replay: score, transcript, tactic chips, pressure line, hang-up point, next-time habit | “The replay explains the tactic and the moment to stop. It focuses on one next step; it does not shame the person practicing.” |
| 2:00–2:25 | Practice and Family Circle | “With an account, practice history builds skills over time. A trainee controls whether a coach can read their transcript; sharing starts off.” |
| 2:25–2:45 | Architecture diagram or code for 20 seconds | “A deterministic Director chooses the tactic and outcome. The language model only writes the caller’s line, which is checked before it is shown. Tests challenge unsafe inputs.” |
| 2:45–3:00 | End on the callback card | “Hang Up builds a practice habit. In a real call, hang up and call back using a trusted number.” |

## Recording checklist

- [ ] An adult has reviewed the current build and the presentation.
- [ ] Record one real practice session only with a person who agreed to participate; otherwise use text mode and say it is a software demo.
- [ ] Show only results the app actually produced. Do not describe the score as proof that a person is safe from scams.
- [ ] Do not add a pilot or accuracy statistic until the human-reviewed data has been collected and reported.
- [ ] Keep the AI disclosure visible and readable in the opening shot.
