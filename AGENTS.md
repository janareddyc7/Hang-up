# AGENTS.md: Hang Up

Hang Up is a web app where an AI plays a scam caller, the user tries not to get scammed, and a replay shows the moment the scam started working on them. Built for the Congressional App Challenge; audience is older adults and the families who look out for them.

## Read before you code

1. `docs/PRODUCT.md`: what the app does, screens, modes.
2. `docs/ARCHITECTURE.md`: how a call works end to end.
3. `docs/ENGINE.md`: the Director, scoring and curriculum. **The engine in `src/lib/engine` is the reference implementation. Do not rewrite it; extend it.**
4. `PLANS.md`: the ordered task list. Work one task at a time, in order.

Task-specific docs: `docs/DESIGN.md` (UI and theme), `docs/DATA_MODEL.md`, `docs/API.md`, `docs/ELEVENLABS_SETUP.md`, `docs/SAFETY.md`, `docs/TESTING.md`.

## Stack (TypeScript only; no Python, no Java)

- Next.js 16 App Router, React 19, TypeScript `strict` + `noUncheckedIndexedAccess`.
- Tailwind CSS v4, shadcn/ui, ElevenLabs UI components. Theme tokens live in `src/styles/theme.css`.
- Voice: ElevenLabs Agents with **Custom LLM** pointed at `/api/llm` (ElevenLabs appends `/chat/completions`). Client: `@elevenlabs/react`; every conversation hook must be inside `ConversationProvider`.
- Models: Vercel AI SDK v7. Use `generateText` with `instructions` (not the deprecated `system`) and `output: Output.object({ schema })` for structured output (`generateObject` is deprecated). Read results from `.output`.
- Zod 4 for every external input and every persona card.
- Postgres (Neon) + Drizzle ORM. Schema: `src/db/schema.ts`.
- Auth: Better Auth with the magic-link plugin and Drizzle adapter (Auth.js is now maintained by Better Auth; do not add next-auth).
- Tests: Vitest (unit, integration), Playwright (e2e). Package manager: pnpm. Hosting: Vercel.

Check current versions with `pnpm view <pkg> version` before installing; prefer the latest stable major.

## Non-negotiable rules

1. **Engine purity.** `src/lib/engine/**` has no I/O, no `fetch`, no database, no React, no Next imports. Same input, same output.
2. **Labels by construction.** Scammer tactics come from the Director's decision. Never classify scammer lines after the fact.
3. **No real organizations in voiced lines.** Personas use fictional names. Every model line goes through `validateLine()`; on failure speak the Director's `fallbackLine`.
4. **No raw user text at rest.** Store only `redact(text, wallet)` output. Never log raw transcripts, wallet numbers or phone numbers.
5. **No voice cloning.** Premade ElevenLabs library voices only, mapped from `voiceRole` in config.
6. **Practice Calls are off by default** and require the trainee's own recorded consent (docs/SAFETY.md). Never place a call without a consent row and an identification first message.
7. **Secrets stay server-side.** The ElevenLabs API key, model keys and the Custom LLM secret never reach the client. Validate env with Zod in `src/env.ts`.
8. **Scoring constants and taxonomy** (`taxonomy.ts`) change only with matching updates to `docs/ENGINE.md` and tests.
9. Never weaken or delete an existing test to make a change pass. If a test is wrong, say why in the PR.

## Working agreement

- One `PLANS.md` task per branch/PR. Title: `T07: Token route and startDrill action`.
- Write or extend tests first for engine and runtime logic.
- Before saying a task is done: `pnpm typecheck && pnpm test && pnpm lint` pass, acceptance criteria in `PLANS.md` are met, docs updated if behavior changed.
- If the spec is ambiguous or contradicts the code, stop and list the question under "Open questions" in the PR instead of guessing.
- UI copy: plain, calm, sentence case, never shaming ("You stayed on 3 turns after the red flag", not "You failed"). See `docs/DESIGN.md`.

## Gotchas

- The Custom LLM route must stream SSE (`text/event-stream`), `data: {chunk}\n\n`, ending `data: [DONE]\n\n`. Use `src/lib/llm/sse.ts`. Set `export const runtime = "nodejs"` and `dynamic = "force-dynamic"`.
- The drill ID reaches the route as `elevenlabs_extra_body.drill_id`. Pass it from the client at session start (docs/ELEVENLABS_SETUP.md).
- The first scammer line is spoken by ElevenLabs from the per-conversation `firstMessage` override; the route is first called after the user's first reply.
- End calls by returning the `end_call` tool call (`endCallFrames`), not by closing the stream.
- ElevenLabs' `simulate-conversation` endpoint is deprecated (removal announced for 31 Oct 2026). Use the local bot harness or the agent-testing endpoints.
